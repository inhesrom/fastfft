# Tuning-only coefficient displacement seam

API: `tuning::shift_coefficient_storage<T>(&mut Arc<dyn Fft<T>>, absolute_shift_bytes: usize) -> Result<(), CoefficientShiftError>`. Errors are SharedOwnership, UnsupportedPlan, InvalidShift, InvalidStorage, InsufficientCapacity, Overflow. Only direct Stockham/FourStep plans support it; Arc::get_mut enforces one strong/no Weak owners.

The seam validates canonical descriptor lengths, radix products, offsets, current displacement, checked ranges, and target initialized length before mutation. It infers the existing displacement rather than trusting a caller-supplied current value. Copying uses initialized bytes only and overlap-safe copy_within. Descriptors remain at their original addresses; every coefficient offset changes, including an empty fine-table offset. Only the vacated, non-overlapping range is zeroed. Nonzero incoming padding is rejected atomically so exact restoration needs no backup allocation. No execution path, production field/layout, allocation geometry, policy, scratch contract, or constructor changed. All added engine methods/helpers are tuning-gated; tests are test/tuning-gated.
