fastfft-arena: benchmark harness comparing Rust FFT libraries

USAGE:
  fastfft-arena run [--suite pow2,smooth,rough,sweep,batch,realworld,datacheck]
                    [--profile full|quick|sweep] [--libs fastfft,rustfft,...]
                    [--core 2] [--prec f32|f64] [--max-n N] [--misalign 8]
                    [--filter prec=f32,dir=fwd,place=ip,n=64|128,maxn=N,minn=N]
                    [--label NAME] [--out DIR] [--timeout 600] [--control-every 25]
                    [--no-verify] [--allow-dirty-env] [--procs K]
  fastfft-arena run-cell --core 2 --spec '<json>'
  fastfft-arena report <run-dir>
  fastfft-arena compare <run-a> <run-b>
  fastfft-arena publish <run-dir> --label <label>
  fastfft-arena env [--core 2]

Libraries: fastfft fastfft/avx2 rustfft phastft/split phastft/interleaved tfhe-fft oxifft fftw
Extra rows: fastfft/avx512 fastfft/avx512-ymm fastfft/sse2 fastfft/scalar fastfft/measure
